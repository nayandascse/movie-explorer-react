# Movie Explorer

A responsive React Movie/TV Show Explorer built with React, Vite, CSS and the free TVMaze API.

## Features
- Responsive home page
- Search shows by title
- Movie/show cards
- Ratings, genres and release year
- Interactive details modal
- Close modal by X, backdrop or Escape
- Loading, error and empty states
- Mobile, tablet and desktop responsive layout

## Run
```bash
npm install
npm run dev
```

API: https://api.tvmaze.com
